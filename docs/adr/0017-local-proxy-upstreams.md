# ADR-0017：本机普通代理上游管理

- 状态：接受
- 日期：2026-10-15

## 决策

使用既有 `RoutingOutbound` 和 `RoutingGroup`，不添加旧二进制拒绝的 profile 字段。名为「本机代理上游」的 select 组统一普通上游选择，成员仅为免认证 loopback HTTP/SOCKS5 端点。接口不接收任意远程主机、URL、凭据或脚本。

首次保存或选择时，若原规则只引用一个可管理本机上游，将它的规则、组成员、已选成员和 final 引用替换为新组，保留该成员为默认。没有引用则只建组、不接管流量；多个原上游分别被引用时拒绝歧义合并，用户先在规则面板明确普通流量用途。新端点不会自动取代默认。任何直接或间接用于 dialer-proxy 的端点不纳入普通上游管理。

普通上游切换与服务出口切换不同：前者绝不增删受保护站点，后者仍按 ADR-0014 处理用户明确的站点范围。两者在 UI 分区。保留原有 DIRECT 兜底，不增加隐式 DIRECT。端口改变不等于最终公网 IP 改变；上游节点改变可能改变非保护流量的公网 IP。

面板和 Agent 调用同一串行 Worker；托盘选择该组也进入同一处理路径。保存前保留本地档案备份，运行中重载前撤销就绪并阻断固定流量；同一 ISP 验证后恢复。重载失败尝试回存旧档案和旧规则，仍报告失败且保持固定保护，不伪造恢复就绪。不退出、重启核心进程，但配置重载会断开现有连接。

显式检测通过系统 curl，禁用用户 curlrc，指定代理与固定 HTTPS 测试 URL、超时和体积限制，无 Cookie、不跟随重定向、不忽略 TLS 校验、不直连兜底。只报告该测试的证据，不替代账号功能或固定出口验证。认证端口不在本版本范围内，凭据仍只从既有本机出口设置进入 Credential Manager。

## 否决的备选

检测明确设置 `--socks5-basic`，不提供用户名密码，排除默认可能启用的 GSSAPI/Windows 身份协商；loopback 测试核对协商方法不包含 GSSAPI。参数语义见 [curl 官方手册](https://curl.se/docs/manpage.html#--socks5-basic)。

- 每次切换直接改 Windows 系统代理：会绕过 AEC 分流和固定保护。
- 用「分流」预设保存新上游：会替换用户现有规则与顺序。
- 复用服务组的保护范围变更：普通上游选择不应解除 Claude 等站点保护。
- 自动修改 XxYun/Clash 配置或启动它们：超出 AEC 的生命周期所有权。
- 将机器上的 7892 和 XxYun 硬编码进发布档案：其他用户端口不同；只保留实际既有默认。

## 验收

公开接口测试覆盖新增与选择不改固定身份、传输链路排除、自环与重复端点拒绝、严格字段、HTTP token/Origin；无头 Edge 操作真实展示服务；固定版本 mihomo 在隔离端口通过两个本地模拟代理完成普通流量切换，目标代理失效不隐式直连，固定流量无证据始终阻断。测试不使用维护者正在运行的网关或真实代理凭据。
