# ADR-0012：界面资源在线更新，核心更新必须另行确认

用户需要改善界面而不中断固定 ISP 服务，同时要求核心变更在停服前由用户确认。界面采用独立、不可变的资源修订版与原子活动指针；程序、relay、内核和更新器脚本的改变归为核心更新。完整包先核验再按文件哈希分类，下载确认不能代替停服确认。仅更新界面入口只选择兼容协议的资源，绝不替换二进制。

首次安装外部资源读取能力仍需完整核心升级。发布时以资源内容摘要命名修订版，保留旧修订版与活动指针备份。资源协议版本不兼容时拒绝热更新，必须完整升级；涉及后端接口或模板占位符契约的变化必须提升资源协议，不能只改页面。活动指针切换后用户手动刷新界面，避免自动刷新丢弃草稿。完整下载仍不是二进制差分下载。

0.5.1 使用资源协议 2，包含快捷路由接口。HTML 固定引用 `/ui/<revision>/...`，旧页面在指针切换后仍读旧资源；编译内嵌回退使用保留名称 `bundled`。不能只保证单文件原子替换而允许一次页面加载混用两套资源。

核心更新在下载校验完成后展示独立确认；拒绝即不停止、不替换。接受后只请求本应用正常退出，核对托盘身份、恢复到日常模式及内核/relay 已停止，再备份替换。恢复不完整或进程未正常停止就终止替换，不强杀、不改注册表。复制失败恢复旧文件；启动失败恢复备份并尝试启动旧托盘。就绪须再次取得网络证据，不能由更新成功推导。

本机页面服务采用最多 32 个并发请求处理者，网络修改仍串行进入 Worker，避免慢检测冻结导航。Agent 访问开关是权限撤销例外：原子保存授权标志，不进入网络 Worker、不改变全局状态，关闭立即拒绝新请求；已接受的操作可继续完成。更新启动同样仅启动固定更新器，其本机确认无法通过 HTTP/MCP 参数绕过。

否决始终重启：纯前端变更会不必要地中断连接。否决把核心更新当作热更新：运行中二进制锁定且旧进程不会加载新逻辑。否决逐文件覆盖在线界面：失败可能留下半套资源。否决无确认的自动更新或 Agent 确认参数：违背用户停服授权要求。否决强杀释放文件：无法保证快照恢复和固定出口保护。

界面参考 Fluent 的导航与渐进披露：主要操作、出口保护、Agent 接入优先，来源与检测详情折叠，规则筛选分页只影响展示，保存保留全量顺序。官方参考：[Accordion](https://fluent2.microsoft.design/components/web/react/core/accordion/usage)、[NavigationView](https://learn.microsoft.com/en-us/windows/apps/design/controls/navigationview)。使用原生 HTML/CSS/SVG，不引入远端字体、CDN 或运行期 UI 依赖。
