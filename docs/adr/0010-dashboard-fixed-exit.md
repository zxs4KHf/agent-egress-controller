# ADR-0010：看板管理与固定 ISP 路径切换

用户要求全面替换 legacy 托盘，并允许在新版看板选择到同一个 ISP 的连接路径、增删和排序站点规则。固定出口模式将 `relay` 变成默认选中 REJECT 的受控组，真实 relay 保留为内部传输出站，独立检测入口只用于核对已配置的精确出口 IP；启动、重载、切换先阻断并关闭本应用内核中的旧连接，核对成功后才放行，失败保持阻断。第一跳的 DIRECT 只连接 ISP 代理，不能让受保护站点直接访问目标站。

受保护站点始终在用户规则之前匹配到 relay。看板使用结构化表单、枚举类型与现有出站选项，复用 loopback、随机 token、Host 和 Origin 校验，所有保存和运行变更经同一 worker 串行执行。普通分流规则仍可选择 DIRECT、REJECT 或配置中的组；修改规则不改变受保护站点和出口身份。

固定出口隧道的候选池仍可在隧道候选之后尝试同一 ISP 代理的直连候选；固定的是最终已验证出口身份，不强制固定某一种第一跳。任何路径放行之前必须独立探测并精确匹配预期出口，不匹配或未知仍阻断。阻断连接时仅删除控制器传输链的连接；无法读取连接报告就返回失败，而不是全局断连或声称已清理。

托盘和看板都提供当前用户登录自启开关，只注册一条 HKCU Run 值，精确指向当前安装的 exe；拒绝覆盖其他安装的注册。登录后尝试进入 Agent 模式，但未恢复会话和接管门仍生效。用户主动创建桌面、开始菜单的托盘与看板快捷方式；看板快捷方式用 `--dashboard`，已有实例时转交打开请求，不另起内核。拒绝覆盖其他目标的同名快捷方式，不注册系统服务、文件关联或 URL 协议。便携目录移动、卸载前先解除自启并移除四个入口。

站点保护与站点检测分开：已有站点保留 trace 检测方式，新增域名默认仅检测 HTTPS 可达性，不声称它提供出口 IP；固定出口的独立 trace 探测仍严格匹配精确 IP。GeoSite/GeoIP 常用内容提供建议，类别是否存在由用户提供的数据文件和内核预检决定。

否掉的备选：直接切任意路由组会改变公网出口；先退出 Agent 模式再进入会短暂恢复原系统代理；仅核对候选主机不能证明公网 IP 相同；在 UI 展示或保存原始 YAML 会扩大私人凭据暴露面。核对证据只证明检测时刻的公网 IP，不能承诺供应商之后永不换 IP；周期检查发现不同或未知时再次阻断。本次用户已明确授权真正切至新版，取代 ADR-0006 的临时 legacy 原样搬迁形态，回滚备份仍保留。
