# ADR-0001：与既有服务隔离

- 状态：Accepted；2026-10-10 由 [ADR-0006](0006-legacy-migration-runbook.md) 补充（旧链路按 Runbook 迁入 `legacy/`，旧目录文件仍不改不删）
- 日期：2026-10-09

## 背景

前身项目的目录 已经承载正在使用的代理链路、端口、守护和实验材料。直接改造会把新产品的安装、测试和故障恢复与现有服务绑定。

## 决策

新产品只在 本仓库 开发和运行。旧目录及其运行中的服务只读；新项目使用独立配置、数据目录、端口和进程名。未来整合必须先有可回滚迁移方案并由用户单独确认。

## 后果

需要复制或重新生成配置，不能依赖旧目录的隐含状态；初期会有少量重复文件，但故障半径和回滚边界清晰。
