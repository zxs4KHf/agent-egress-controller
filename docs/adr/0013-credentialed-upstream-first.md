# ADR-0013：已配置凭据的出口优先认证

2026-10-14 的本机隔离诊断发现，匿名握手可能被静默丢弃，而带凭据的连接能取得同一预期出口证据；先匿名会消耗短拨号预算。S7/S8 因此从 legacy 的匿名优先改为已配置凭据优先，失败仍尝试匿名白名单方式，SOCKS 每次仍只报一种方法；无凭据只匿名。回归覆盖静默匿名请求、认证成功和仅接受匿名的供应商。

否掉的备选：无限延长拨号预算会超过内核拨号时限，并放大重试拥塞；删除匿名回退会破坏白名单供应商兼容；直接改走其他公网出口违反固定出口要求。认证优先不能修复远端重置、不可达或供应商故障，必须与真实链路可用性分开报告，未取得精确出口证据仍不能放行。
