# 0.5.6 发布说明与验收范围

日期：2026-10-17。候选汇总重新检测/G3 热修复、选定站点协作、浏览器两范围预览恢复及 UI 整理。不包含尚未完成的管理员防绕过服务。公开发布状态与 CI 链接以 GitHub Release/PR 为准。

## 用户可见变化

- 新增 CVR 2.5.8 默认订阅脚本的持久规则安装/撤销、只读运行核对和可选 DNS/ECS 权威诊断。只管确认的站点，保留 Clash 系统代理、普通规则与节点；不自动激活或重载。用户在 Clash 手动重新激活后核对。自定义/共享脚本、未知版本、GUI DNS 接管或外部编辑拒绝自动覆盖。
- 普通网站、GPT 与 Arena 不新增强制绑定；固定专用入口受原 ISP 身份门控制。UDP 前置拒绝，局部 DoH 不回退，标准 ECS 零长度覆盖。规则存在不是实际端点、固定 ISP 或全浏览器无泄露证明。
- 浏览器设置提供仅 AI / 全局两范围，预览并本地确认、恢复原值；全局目前限普通 Edge，排除 Chrome/CfT 及其独立指纹实例。静态图标改中性紫色，托盘保留状态色并分层。站点搜索折叠、规则筛选分页、导航和双向 Agent 控制回归。
- 规则安装和浏览器失败均保留带时间错误码，Agent 可直接读取。修复无效 JS 被误认默认模板、CVR 异常回退、草稿未使计划失效及 restore/state 忽略额外 force 字段的问题。
- 健康固定出口重新检测时先核对身份，不关闭既有连接、不重新选择路径；身份未知或不匹配仍立即阻断。恢复时验证原路径，不切换预期 ISP IP。
- G3 读取正在运行的内核实际启动日的日志，不再跨 UTC 午夜寻找不存在的新文件。检测请求禁用 WinHTTP 全局连接池和 keep-alive，避免旧连接导致本轮没有新记录；证据不足仍显示未知。
- 固定模式下 Claude/Anthropic 域名族始终优先经过受控 relay，普通上游或服务组切换不能解除这些域名的保护。
- 退出时保留其他程序已接管的系统代理；读回确认不再指向 AEC 后，该恢复项可完成。其他全局设置的冲突仍不覆盖。

## 尚未解决的范围

- Windows 系统代理只有一份。Clash 将其改为自己的端口后，普通浏览器可能不经过 AEC；AEC 只告警，不循环抢写。应用内 Claude 锁定不能阻止完全绕过 AEC 的流量。
- G3 不是浏览器 DNS 泄露检测。新增权威 TXT 探针需要单独同意，仅两次限定查询，不声称消除网页报告或所有日常浏览器泄露；不改 Windows DNS。Clash 仅在用户确认安装时追加选定站点策略。运行 API 缺少端点/DNS policy 回读，因此总运行验证不变绿。
- 管理员阻断服务尚未完成，不打包、不安装、不启用。未将 Arena 自动纳入保护范围；用户独立指纹浏览器的 profile 与出口继续由用户管理。
- 隔离模拟代理通过不代表真实供应商或 GPT/Claude 账号实测；不读取聊天、不发送消息。发布不自动停止或升级维护者本机服务。

## 升级与回滚

0.5.3 及新版更新器按组件 SHA256 只下载变化组件，未变化的 pinned mihomo 不重复下载。包含程序变更，安装前必须单独确认短暂停服；取消保持旧服务运行。旧版本引导见 [升级指南](UPDATING.md)。

更新保留路由选择、固定 ISP、端口、凭据与自启，不替用户选择 GPT 或普通上游。安装目录的 `.aec-update-backup/` 保留程序备份，失败按清单回滚，数据与密钥不覆盖。安装版与便携版不自动迁移数据，发布包仍未签名。
