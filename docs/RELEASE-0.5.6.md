# 0.5.6 发布说明与验收范围

日期：2026-10-16。针对重新检测引起的断连和跨日 G3 未知发布小补丁，不包含尚未完成的管理员防绕过服务。

## 用户可见变化

- 健康固定出口重新检测时先核对身份，不关闭既有连接、不重新选择路径；身份未知或不匹配仍立即阻断。恢复时验证原路径，不切换预期 ISP IP。
- G3 读取正在运行的内核实际启动日的日志，不再跨 UTC 午夜寻找不存在的新文件。检测请求禁用 WinHTTP 全局连接池和 keep-alive，避免旧连接导致本轮没有新记录；证据不足仍显示未知。
- 固定模式下 Claude/Anthropic 域名族始终优先经过受控 relay，普通上游或服务组切换不能解除这些域名的保护。
- 退出时保留其他程序已接管的系统代理；读回确认不再指向 AEC 后，该恢复项可完成。其他全局设置的冲突仍不覆盖。

## 尚未解决的范围

- Windows 系统代理只有一份。Clash 将其改为自己的端口后，普通浏览器可能不经过 AEC；AEC 只告警，不循环抢写。应用内 Claude 锁定不能阻止完全绕过 AEC 的流量。
- G3 不是浏览器 DNS 泄露检测。网页观测到国内解析器与 AEC 缺少日志证据是不同问题。本版本不自动修改 Windows、Clash 或浏览器 DNS，也不声称已消除网页报告的 DNS 泄露。
- 管理员阻断服务尚未完成，不打包、不安装、不启用。未将 Arena 自动纳入保护范围；用户独立指纹浏览器的 profile 与出口继续由用户管理。
- 隔离模拟代理通过不代表真实供应商或 GPT/Claude 账号实测；不读取聊天、不发送消息。发布不自动停止或升级维护者本机服务。

## 升级与回滚

0.5.3 及新版更新器按组件 SHA256 只下载变化组件，未变化的 pinned mihomo 不重复下载。包含程序变更，安装前必须单独确认短暂停服；取消保持旧服务运行。旧版本引导见 [升级指南](UPDATING.md)。

更新保留路由选择、固定 ISP、端口、凭据与自启，不替用户选择 GPT 或普通上游。安装目录的 `.aec-update-backup/` 保留程序备份，失败按清单回滚，数据与密钥不覆盖。安装版与便携版不自动迁移数据，发布包仍未签名。
