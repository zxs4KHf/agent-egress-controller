# 0.5.4 发布说明与验收范围

日期：2026-10-15。面板、托盘与 Agent 统一管理多个本机代理上游；保留增量更新、安装包、独立任务栏与固定 ISP 保护。

## 使用方式

在「规则、站点与路径 → 本机代理上游」新增名称、loopback 地址、实际端口和 HTTP/SOCKS5 协议。mixed 端口可选任一协议。保存不自动替换原默认；检测不自动切换。已有唯一普通上游被接入选择组，GPT 原来走 XxYun 时保持 XxYun；Claude 保护及 ISP 身份不变。新装不硬编码本机端口；尚无规则引用时明确显示未接入，可在规则面板选择该组。

托盘在 Agent 模式列出「本机代理上游 → 名称」，一键切换。Agent 使用 `aec_upstreams`、`aec_upstream_save`、`aec_upstream_select`、`aec_upstream_delete`、`aec_upstream_probe`；HTTP 使用同名工具。端口仅允许免认证 loopback，最多 16 个，名称作为稳定标识；修改地址、端口和协议可保留名称。

## 验证

[已验证，本地隔离] 无头 Edge 真实页面新增、修改、检测、选择、删除；Rust 公共接口覆盖保护不变、自环/重复端点、链路出站排除、HTTP token/Origin 和未知字段；真实 mihomo 加两个本地模拟 HTTP 代理确认普通流量从 XxYun 模拟端切到 Clash 模拟端，失效端点无自动直连，Claude 无固定证据始终阻断。此结果不是用户真实账号或供应商可用性证明。

发布门槛：fmt、clippy、全部 Rust/pinned mihomo 测试、PowerShell 5.1 更新器与增量日志测试、三轮原生窗口身份、Edge 交互、NSIS 安装包、旧更新器兼容和真实发布包增量/回滚测试均通过。GitHub Windows CI 和公开资产验证链接附 Release，未通过不得公开发布。

## 升级与回滚

含核心变更，完整更新需要用户单独确认短暂断连；仅界面更新不提供新核心功能，旧核心界面会提示完整升级。0.5.3 更新器可增量获取；更旧更新器依照 UPDATING.md 引导或全量升级一次。保留数据和凭据，旧版本资产不覆盖。程序备份在 `.aec-update-backup/`，上游配置变更前另存数据目录 `upstreams-before.json`。恢复配置需先正常退出本安装，禁止运行中直接覆盖。

[边界] 本次不升级、停止、重启维护者生产网关，不改变其 GPT/XxYun 或 Claude/固定 ISP 选择。客户端须自行保持内核运行，关闭竞争的系统代理/TUN 接管。运行中应用上游配置可能短暂断开现有连接，固定流量核对同一 ISP 后恢复；原有 DIRECT 兜底保留。多个既有本机上游分别被规则引用时拒绝自动合并，不猜测用户用途。程序仍未签名。
