# 项目范围与现状

> 文中的 **legacy** 指本项目的前身：维护者此前在 Windows 上自用的一套出口链路（mihomo + Python relay + PowerShell 脚本 + 托盘）。它不随本仓库发布，只作为行为参照和「外部写入者」探测的样本出现。

## 1. 当前参考项目实际包含什么

参考目录 前身项目的目录 是一个 Windows 本机代理/出口编排器，不是软路由：现有 mihomo 配置不开 TUN、不接管局域网、不提供网关/NAT/DHCP。已有脚本把 mihomo、TCP relay、守护、监测、系统代理切换、浏览器/CLI 启动入口、语言/时区切换和托盘组合起来。

### 可迁移的核心能力

- mihomo 代理内核和上游出口配置
- TCP relay 与固定出口/备用出口链路
- 系统代理和显式应用代理切换
- Agent/日常模式的语言、时区和浏览器启动参数
- 出口健康检查、目标域名连通性验证和日志
- 托盘菜单、启动项和退出恢复流程

这些材料是只读参考。新产品必须复制、重构或重新配置后使用，不能直接连接旧项目的运行状态。正在运行的链路按 迁移 Runbook（维护者本地文档，不随仓库发布） 原样迁入 `legacy/`（ADR-0006）；新产品最终替换 legacy。

### 2026-10-10 只读核查补充

- 系统代理当前指向旧 mihomo（`127.0.0.1:7893`），时区为旧 agent 模式的 `Eastern Standard Time`；旧项目在登录时和托盘里都会写这两项。因此全局写入必须走接管门（ADR-0004）。
- 浏览器语言不能靠切系统语言实现：系统 UI 语言要注销才生效。旧项目实测，有效手段是浏览器进程级的 `--lang` 和 `--accept-lang`。同一 profile 已有实例运行时，新启动参数会被静默丢弃。
- 时区用 `tzutil` 切换，旧托盘以普通权限运行时能生效（推断：标准用户默认有改时区的权限，新产品仍需实测）。
- MSIX 打包的 ChatGPT/Codex 桌面端不接受 `--proxy-server`，只能靠系统代理覆盖。

### 应隔离的非核心能力

- Codex 官方/Sub2API/BPS/Prism 渠道切换
- “降智”研究、模型路由、账号画像和会话状态实验
- Cookie/STATE 获取、动态住宅池探针和票据中继
- 与出口控制无关的 Astra 示例服务
- 任何硬件、浏览器或账号指纹伪造/随机化

## 2. 新产品解决的需求

用户需要的是一个本机控制面：把固定的网络出口、代理作用域、DNS、语言、时区、浏览器 profile 和 Agent 启动入口组合成可切换的工作模式，并让用户知道当前环境是否真的可用。

它不是：

- 局域网软路由或家庭网关
- AI API 渠道管理器
- 模型质量、降智或账号风控解决方案
- 反检测浏览器或机器指纹伪造工具

## 3. 模式与状态

### Agent 模式

进入前创建环境快照，然后依次启动代理链路、设置允许的本机环境、启动指定的 Agent/浏览器入口，执行环境验收。只有硬门槛通过，才显示“Agent 模式已就绪”。

### 日常模式

退出 Agent 模式时按快照恢复系统代理、环境变量、语言/时区、应用启动状态和 profile 选择，并逐项验证。失败项要保留在托盘和窗口中，直到用户处理或确认。

### 环境验收四态

- 通过：证据满足目标
- 警告：不影响核心工作，但存在可见风险或只读信号
- 失败：硬门槛不满足
- 未知：检测未完成或证据不足，不能当作通过

硬门槛包括出口/代理实际生效、目标域名可达、DNS 路径符合档案、时区/语言一致。语言门槛针对 Agent 启动入口的进程级语言，系统显示语言只读展示。WebRTC、Canvas、WebGL、Cookie 等只读信号不参与机器指纹伪造，也不产生总分。

## 4. 配置与排查提示词

首次配置用设置页表单。不做可视化问答（ADR-0005）。

每个失败或未知检查项、恢复失败项和设置缺项，都附一段可复制的排查提示词。内容包括目标设置、当前证据、允许修改的本机范围、验证命令和回滚要求；不包含秘密，不自动发送给外部 Agent。

## 5. 第一版验收

- 新产品开发实例启动和退出，不会改变旧目录或 legacy 链路的进程、配置、代理状态或端口；全局写入只在接管门打开时发生。
- Agent/Daily 两个 profile 可保存、切换、恢复和逐项验收。
- 用户能看到实际出口 IP/ASN/地区、延迟、目标域名状态、DNS、WebRTC 和浏览器只读信号的来源与时间戳。
- 关键检查失败或未知时，不显示“Agent 模式已就绪”。
- 关闭窗口进入托盘；明确的退出动作先恢复日常模式。
- 能为失败或未知项生成并复制排查提示词；生成与发送分离。
- 形成 Windows 10/11 安装包和可回滚便携包；后续再考虑 TUN。
