# 升级到 0.5.2

下载入口：[v0.5.2 Release](https://github.com/zxs4KHf/agent-egress-controller/releases/tag/v0.5.2)。任务栏独立分组修复属于程序更新，**仅更新界面不会安装此修复**。更新器仍下载完整 ZIP，只替换改变的允许文件，不是二进制差分下载。

| 当前版本 | 升级方式 |
| --- | --- |
| 0.5.1 | 托盘或看板「检查完整更新」直接升级 |
| 原版 0.5.0 | 先按下方步骤替换一次更新脚本，再从原托盘「检查并安装更新」升级 |
| 早于 0.5.0 | 没有更新入口，按[用户指南](USER-GUIDE.md#退出更新与交付)手动升级 |

## 0.5.1：直接使用更新器

1. 保存控制中心草稿。在托盘或看板「更新与维护」选择「检查完整更新」。
2. 确认下载。更新器从本项目 GitHub Latest Release 获取完整 ZIP 和同版本 SHA256 文件，并核验包内清单。
3. 出现核心停服确认时，选择方便短暂断网的时间继续。取消不会停服或替换文件。只正常关闭本应用的托盘、控制中心及网络子进程，不强杀其他程序；恢复不完整或文件被占用则中止。
4. 更新器备份并替换程序、按原模式启动托盘；是否联网就绪仍以重新检测为准。
5. 从托盘点「创建桌面和开始菜单快捷方式」，再打开看板。更新器不会自动重写旧快捷方式或任务栏固定项。如果旧固定入口仍有缓存，只取消固定旧的 Agent Egress 入口，再从新看板固定；不要取消固定 ChatGPT。

更新不重置规则、出站组选择、固定 ISP、端口、凭据或登录自启。若用户原先设为 OpenAI 走本机日常代理、Claude 走固定 ISP，升级保持这些选择，不切换 ISP IP。

## 0.5.0：一次性更新器引导

**原因：** 原版 0.5.0 的包路径白名单没有 `app.ico`、`ui/` 和中文使用说明文件。它会在停服前拒绝新包，因此即使新包包含修好的更新器，旧更新器也无法替换自己。不能通过关闭校验或改写旧 Release 资产解决。

1. 关闭正在运行的更新检查窗口。无需为了复制脚本停止网络服务。
2. 从同一个 v0.5.2 Release 下载 `aec-update-0.5.2.ps1` 和 `SHA256UPDATER-0.5.2.txt`。这份脚本与完整 ZIP 里的 `aec-update.ps1` 字节一致。
3. 在下载目录打开 PowerShell，核对 SHA256。下面只校验，不运行下载的脚本：

   ```powershell
   $actual = (Get-FileHash -LiteralPath '.\aec-update-0.5.2.ps1' -Algorithm SHA256).Hash
   $line = Get-Content -LiteralPath '.\SHA256UPDATER-0.5.2.txt' -Raw
   if ($line.Trim() -notmatch '^([a-fA-F0-9]{64})\s+\*?aec-update-0\.5\.2\.ps1$') { throw '校验文件格式错误' }
   if ($actual -ne $Matches[1]) { throw 'SHA256 不匹配，不要安装' }
   'SHA256 核对通过'
   ```

4. 找到**实际正在使用的安装目录**（包含 `aec-tray.exe`）：把原 `aec-update.ps1` 复制为不重名的备份，再把下载脚本复制到这个目录并命名为 `aec-update.ps1`。仅替换这一份脚本，不动 `data`、`portable.flag`、程序或凭据。不要双击脚本，也不要覆盖另一份安装。
5. 原版 0.5.0 的更新菜单只在日常模式可用。手动选择「退出 Agent 模式」，确认恢复完成，再选「检查并安装更新」。此时开始的断连由用户主动退出造成，不是复制脚本造成。
6. 新脚本执行下载、完整校验和独立停服确认，再在原目录备份替换并启动托盘。由于原版 0.5.0 不传递恢复模式参数，升级后需手动「进入 Agent 模式」。最后创建/修复快捷方式并打开看板。

如果不希望替换脚本，可按用户指南备份后手工升级完整 ZIP。不要直接把便携数据搬到一个全新的安装 EXE 目录：便携与安装版的数据位置不同，安装器不自动迁移。

## 备份、回滚与边界

更新器在安装目录 `.aec-update-backup/<时间戳>-<标识>/` 保存旧程序和 `rollback.json`。失败复制会自动恢复；新版托盘启动失败时尝试回滚并打开旧程序。手动回滚前先正常退出并确认系统恢复完成，再按清单恢复旧文件、移除此次新增文件，保留 `data`、用户 Geo 文件和凭据。快捷方式修复是独立操作，不包含在程序文件回滚清单内。

程序未签名；SHA256 只能检查与本项目发布资产是否一致，不能代替可信来源判断。升级成功不能证明供应商链路或账号可用。全局接管和固定出口保护保持原约束，未知出口不会被当作通过。Agent 能打开更新器，不能替用户确认停服。
