# 0.5.3 发布说明与验收范围

日期：2026-10-15。新增组件级增量下载、持久更新日志、离线 CLI 与 MCP/HTTP 更新诊断；不修改网络路由、固定出口、快捷方式或用户档案格式。

## 交付内容

安装 EXE、完整便携 ZIP、各自 SHA256、独立更新脚本及校验文件继续保留；新增 `aec-incremental-0.5.3.json`、`SHA256INCREMENTAL-0.5.3.txt` 和 `aec-0.5.3-<组件>.zip`。用户新装选安装包/便携包，不需手工拼组件。更新器自动选变化组件，完整包仍供兼容/回退，不改写旧发布资产。

旧更新器不会自动获得增量能力：0.5.1/0.5.2 先完整升级一次，或按[升级指南](UPDATING.md)校验后替换独立脚本，本次即可增量；0.5.0 必须脚本引导。只是脚本替换不需停网关，实际核心替换仍需用户单独确认。`aec-agent update-status` 需新版 Agent，可独立解压运行并指定数据目录，不启动网关。

## 验证与发布门槛

**[已验证，本地隔离]** PowerShell 5.1 回归从无增量/无日志能力开始，合成文档更新经真实 loopback HTTP 只下载 756 字节、跳过 1 MB 未变测试内核；核对组件/逐文件 SHA、重建包、在线安装、取消、UI-only、重复无下载、数据保留和回滚。注入超时后日志仍可由不连接托盘的真实 `aec-agent update-status` 读取；含测试秘密的原始异常未入日志。日志不可写也不得阻止恢复回调。

必须全部通过后才发布，具体 CI 运行链接和最终下载节省数据附 GitHub Release：

1. fmt、clippy、Rust 单元/集成及 pinned mihomo 测试。
2. 更新器 SelfTest、`packaging/test-incremental-update.ps1`（PS5.1，真实 HTTP 与离线 Agent）、三轮窗口/快捷方式身份、Edge 页面交互与 NSIS 编译。
3. GitHub Windows CI 构建完整包/安装包/组件清单。`test-release-upgrade.ps1` 用固定历史 0.5.0/0.5.1/0.5.2 源码，对真实新 ZIP 验证原版拒绝/直接/引导升级、便携与安装模式、合成数据保留及回滚。
4. 从官方重新下载固定哈希的真实 v0.5.2 ZIP，使用新增量算法跳过未变 mihomo，验证所有新文件哈希、重复零负载和完整回滚；生命周期由测试替身处理，不启动实际代理。
5. 发布后重新获取公开资产校验并重跑兼容/增量测试，核对 Latest 发现所需资产。

**[未验证/边界]** 本次不升级、停止、重启维护者生产网关；不宣称测试证明用户的真实 OpenAI/Claude 账号或供应商连接正常。组件下载不是二进制补丁，不保证固定节省比例，也未实现断点续传/跨次缓存。程序仍未签名，SHA256 不是发布者签名。完整包与组件同由官方 GitHub Release 提供，信任边界未扩张为任意更新源。

## 失败和回滚

先读取 `update-status` 中失败阶段、错误码、HTTP 状态、下一步建议。下载/校验失败不得安装；日志中未终结状态为 unknown。复制失败恢复备份，启动失败尝试旧程序恢复；恢复失败必须保留现场，不能强杀、关闭校验或把 AI 流量改到其他出口。备份在安装目录 `.aec-update-backup/`，用户数据与凭据不参与文件回滚。详细操作与旧版本限制见[升级指南](UPDATING.md)。
