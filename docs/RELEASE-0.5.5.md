# 0.5.5 发布说明与验收范围

日期：2026-10-15。修复 Agent 启动链路和更新弹窗的独立任务栏身份，保留多个本机上游、组件增量、更新日志和固定出口保护。

## 用户可见变化

从打包的 Codex/ChatGPT 类启动器进入时，AEC 在显示窗口或启动网络前检查并脱离宿主包身份。控制中心使用自己的盾牌图标和任务栏分组；快捷方式继续使用稳定 AppID，重开命令不保存会话令牌。更新确认、结果和错误窗口使用独立的 AEC 更新图标；默认「取消」，只有点击「继续」才确认当前步骤。下载确认不代表已同意停服，核心安装仍另外确认。

这修正了 0.5.2–0.5.4 只验证窗口标识的不足：窗口 AppID 正确时，进程仍可能继承宿主包身份。旧的运行中窗口不会因 Release 发布自动改变。

## 验收入口与结果

[已验证，本地隔离] `cargo fmt --all --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test -- --include-ignored`。覆盖真实 Win32 托盘菜单消息 XxYun → Clash → XxYun、面板/Agent 公共接口、真实 pinned mihomo 和两个模拟代理；普通路径切换不修改 Claude 固定保护和预期出口，失效上游不自动绕过保护。

发布门槛还包括：实际打包宿主的独立启动/参数/退出码、三轮真实控制中心窗口身份、更新弹窗取消、PowerShell 5.1 更新器与增量日志、无头 Edge 面板交互、NSIS 安装包，以及旧版本到新发布包的增量校验/取消/备份/回滚。GitHub Windows CI 和发布资产的验证结果附在 Release；未全部通过不得公开发布。

[边界] 上游为隔离模拟端点，不代表真实 Clash 供应商或 Claude/GPT 账号实测。窗口与进程属性是原生验收证据，不替代所有 Windows 主题/缓存状态的人工外观验收。CI 普通宿主不覆盖打包宿主继承，本机 Codex 的 fixture 单独覆盖该分支。不读取用户聊天、不发送测试消息、不改生产路由、不升级或重启维护者本机网关。

## 升级、快捷方式与回滚

0.5.3/0.5.4 更新器可按组件增量升级，保留原 GPT/XxYun、Claude/固定 ISP 配置和所有凭据。**包含程序变更，必须确认短暂停服才安装。** 若希望首次下载确认弹窗就独立显示，先按 [升级指南](UPDATING.md) 校验并替换 0.5.5 单独更新脚本，再重新打开更新入口；这一步不需要停网关。正在运行的旧脚本窗口不能原地变成新窗口。

升级后从托盘「创建桌面和开始菜单快捷方式」修复本安装入口；不同安装或自定义目标不会被覆盖。旧固定项仍显示缓存时，仅取消固定旧 AEC 项，再固定新控制中心，不操作 ChatGPT 固定项。

备份在安装目录 `.aec-update-backup/`，失败按清单恢复程序，数据和密钥不覆盖。取消不会停服。安装版与便携版不自动迁移数据；新版本仍未签名。详细根因与兼容性取舍见 [ADR-0018](adr/0018-independent-desktop-launch.md)。
