# 0.3.0 验收与交付边界

日期：2026-10-12。Windows x64 便携预览版；沿用 pinned mihomo v1.19.31。源码与包均不含维护者出口账号、数据目录或私人路由表。

## 本次变化

本机看板管理保护站点、有序规则和固定 ISP 第一跳；登录自启开关与四个快捷方式入口；Claude 桌面版只读分流证据；relay 等待和流式响应不再继承握手阶段的短超时。行为与限制见 USER-GUIDE 和 ADR-0010。

## 已验证

- `cargo test -p aec-core site_edits_preserve_probe_type -- --nocapture`：修复前失败（已有 reachability 站点被改成 trace），修复后通过。新增网站不声称提供出口 IP。
- `cargo test -p aec-core setup::tests`：13 项通过，涵盖 token/Host/Origin、防源字段回显、startup/shortcuts 的有效调用与无效调用拒绝；测试后端不写真实注册表。
- `cargo test -- --include-ignored`：核心 185 项通过，真实内核进程管道 1 项、relay_chain 2 项、托盘 1 项通过。固定 gate 测试验证启动阻断、独立 probe、保护优先、重载阻断、已建立连接关闭和再次放行。测试仅使用本地合成出口，不写系统代理或时区。
- `cargo clippy --all-targets -- -D warnings`、`cargo fmt --all --check`：通过。
- `cargo build --release --workspace --locked`：三个发布 exe 构建通过。
- 合成看板浏览器验收：新增 domain-suffix 规则、保存、路径选择、自启选择保存与重新加载正确；周期刷新不会覆盖尚未保存的选择。未调用实际系统自启 API，未包含私人地址。
- 新安装目录的 `--create-shortcuts` 在本机实际创建四个 `.lnk`；逐一读取确认桌面/Programs 下的 Controller 指向该 exe、Dashboard 指向该 exe 加 `--dashboard`。
- 维护者旧表只读导入验收保留 10 出站、4 组、72 有序规则，pinned 内核校验通过，旧代理与隔离导入出口相等；IP 不公开。
- 私人切换档案准备保留转换后的 71 规则、2 候选协议；官方第一跳经独立 probe 的精确出口相符；准备流程不写系统代理或时区、不停止旧服务。私人档案不进入发布包。

## 未验证与限制

- 尚未证明其他用户机器上的网络、隧道节点、标准账号权限、登录后启动与关机恢复。维护者旧 guard/monitor 无正常退出接口，实际全局切换另行执行，不用准备成功冒充已切换。
- 真实 Claude 请求由用户测试；不自动发消息，R11 只是当前稳定连接样本，不覆盖 MCP、Cowork 或忽略系统代理的子组件。
- 固定出口只保护经本应用的指定域名流量。普通 DIRECT 仍可用；精确出口证据只证明检测时刻，约 30 秒巡检不能保证供应商两次检测之间不换 IP。
- 没有迁移旧 guard 反复抢回系统代理的行为；检测外部改写会撤销就绪并告警，不与其他工具争抢。未实现自动重启所有故障服务，需根据报告恢复或重新进入。
- 无安装包和代码签名，不自动下载。GeoSite/GeoIP 由用户提供可信文件；常用类别建议不保证每个数据文件都包含。
- 设置页保存凭据与档案不是跨 Credential Manager/磁盘的事务；磁盘写入失败需按提示核对凭据与档案，不把失败当作成功。

## 升级与回滚

关闭旧安装自启，正常退出并完成恢复，备份 data；解压新包到新目录，复制档案并在当前用户凭据管理器补齐账号。新目录重新启用自启、创建入口。另一份安装的自启/同名快捷方式冲突会拒绝覆盖，先移除旧入口。回滚时关闭新版自启、恢复并退出，重新打开备份的旧安装。不得覆盖已发布的 0.2.0 包或向用户分发运行中的 data/core。
