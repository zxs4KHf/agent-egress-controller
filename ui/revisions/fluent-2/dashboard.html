检测到系统代理已经被更改

其他软件或系统操作改变了代理入口，当前会话已失去验证，无法保证日常应用仍经固定 ISP。

  1. 从托盘或看板退出 Agent 模式。
  2. 关闭 Clash 等其他客户端的“系统代理”开关，保留需要的代理内核运行。
  3. 重新进入 Agent 模式，检测通过后再使用。

AEC 不会抢回代理。重新检测或恢复原端口不能解除本次警告，无需重启 Windows。

方式一 · 客户端系统代理的站点规则 安装状态未知 / 未验证

仅方式一需要安装并激活这里的规则：普通网站由 Clash 原规则分流，仅明确选定站点转交 AEC 固定 ISP。方式二由 AEC 本地接管，无需修改 Clash 站点规则，可在此撤销历史受管块。AEC 不重载 Clash、不切节点或端口；普通 IP 检测页不代表 Claude 的出口。

DNS / ECS 权威检测（可选外网请求）

经当前 Clash 解析器和 AEC 固定入口的 Google DoH，分别向 dnscheck.tools 发送一次随机 TXT 查询。不会把检测站永久加入规则。第三方将看到随机诊断请求及递归器来源；失败为未知。只覆盖这两次查询，不是所有 Claude 域名、日常浏览器或整机的无泄露证明。

安装、激活、DNS 与失败关闭边界

自动安装仅支持核实版本的 Clash Verge Rev 2.5.8 当前订阅已注册且独占的默认脚本，需要客户端已有本机控制器供只读核对。自定义脚本、共享脚本、GUI DNS 接管等情形拒绝覆盖。安装只追加自己的尾块，不改订阅、节点选择或指纹浏览器。之后请在 Clash 官方界面手动重新激活当前配置（可能短暂影响连接），再点“只读运行核对”。

客户端必须保持规则模式、内核 DNS 生效；Global/Direct、切换到未安装的订阅、关闭系统代理或绕过它不在这份规则的保护范围。脚本异常可能被客户端回退，不能作系统级绝对阻断保证。正常规则输入发生冲突时返回选定域名 REJECT，不影响其他原规则。

选定站点使用固定入口 DoH、标准 ECS 零长度覆盖及前置 UDP 拒绝；DoH 不等于剥除所有 ECS。运行 API 不回显 DNS 策略或 HTTP 节点地址，规则通过不代表 ISP 身份或浏览器全部通过。Arena 和独立指纹浏览器不自动接管。

AEC 托管普通上游（兼容模式）

系统代理继续指向 AEC；这里选择 XxYun、Clash 等普通上游，不修改受保护站点或固定 ISP。运行中应用修改可能短暂中断连接，不退出网关服务。

新增本机上游

名称是稳定标识；修改时保留名称。只支持免认证本机端口，不接受远程地址或 AEC 自己的端口。

端口、检测与代理共存说明

XxYun 和 Clash 的内核保持运行，关闭它们的“系统代理”和 TUN 接管，节点照常切换。端口以客户端实际配置为准，同地址、同 TCP 端口不能被两个客户端同时占用。HTTP 与 SOCKS5 必须匹配；mixed 端口两者均可。

检测只通过选定上游访问 Cloudflare HTTPS 测试站，最长约 8 秒，不自动切换或回退直连。通过不代表 GPT 登录成功、全部网站可用或 Claude 固定 ISP 已验证。新增上游不自动替换当前选择。原有规则中的 DIRECT 兜底仍保留，本功能不新增直连兜底。

服务出口切换

与托盘使用同一开关。与上方普通上游切换不同，这里选择非固定出口会取消该组域名的固定 ISP 保护；选择固定 ISP 会恢复保护并核对出口。切换会重载规则并短暂中断现有连接。

固定 ISP 连接

连接原理与验证边界

切换时先阻断受保护流量并断开旧连接；只有新路径的出口 IP 精确匹配配置才放行。核对失败保持阻断，不借其他 IP 恢复访问。巡检证据只代表检测时刻，供应商之后更换 IP 仍会触发阻断。

受保护站点

域名及子域名优先走固定 ISP，普通分流规则不能覆盖。

保护与检测有什么区别？

删除站点会取消该站点的固定出口保护。新站点默认只检测 HTTPS 可达性，不能据此证明出口 IP。oaiusercontent.com 使用 files.oaiusercontent.com 检测，但保护覆盖整个域名及子域名。

浏览器环境 · 范围与恢复 运行证据另行检测

仅 AI 浏览器不改日常浏览器。全局范围当前仅支持普通 Edge 的全部 profile；Chrome / Chrome for Testing 及使用它们的独立指纹浏览器排除。指纹浏览器若改用 Edge，不能使用全局范围。

全局语言策略只改变 Edge 界面语言，不保证所有网站的 Accept-Language；不会修改 Windows 显示语言。系统时区仍是出口设置中的独立接管项，会影响整机。

预览五分钟后失效，改选项须重新预览。策略写入前记录原值，外部程序改过的值不覆盖。应用不会关闭浏览器或网关；需用户自行重开浏览器后采集证据。DNS / WebRTC / UDP / EDNS-ECS / IPv6 未取得证据仍为未知，不能凭设置保存就判定安全。

启动入口与登录自启

可在 Windows 搜索 Agent Egress。移动便携目录前先关闭自启，移动后重新创建入口。检测失败或未完成恢复时，自启不会代表已就绪。

更新与维护

界面更新保持网络服务运行；完整更新先下载并检查差异，涉及核心程序时会弹出独立的停服确认。取消确认不会停止服务。旧版需先完整升级一次才能热更新界面。

0.5.3 更新器按文件哈希仅下载变化的组件，确认框显示下载量；旧更新器需完整升级一次或先校验替换独立脚本。仅更新界面不会改变核心版本。

失败后如何让 Agent 排查？

新版更新器在数据目录 update-logs 保留阶段、错误码与下载记录，关闭弹窗不会丢失。请让 Agent 调用 aec_update_status；托盘/API 未运行时，使用新版 aec-agent.exe update-status 离线读取。Agent 不能替你确认停服，未完成记录也不代表更新成功。用户配置和回滚备份会保留。
