出口代理

多个端口用逗号分隔，必须是同一个出口（同一台机器）；某个端口协议不同，就写成 12323/http。连不上一个会自动换下一个。
密码保存在 Windows 凭据管理器，档案只保存引用；页面不会回显已保存的密码。

系统级分流

留空或 0 使用默认端口。接替已有代理时，填写客户端当前使用的入口端口；不会改写用户级代理环境变量。保存后下次进入生效。若本机程序依赖这个端口，先核对，避免断网。

检测站点
每行一个，每次逐项检测（G2）。预设会为这些站点生成出口规则；导入表保持原规则。要能读到 /cdn-cgi/trace 才能比对出口。

时区与语言

高级：转发层
转发层替你连出口：一个端口或一条路不通，就换下一个，出口 IP 不变。
只限制「正在建立」的连接，已经连上的不占名额。Claude、ChatGPT 客户端会一次新建很多连接，太小会排队失败。
直连出口时每一步最多等多久；隧道自己会多等一些。
在这段时间里把所有路轮流试一遍。必须小于 5000：内核等一个连接最多 5 秒。
