快捷出口切换

与托盘使用同一开关。选择非固定出口会取消该组域名的固定 ISP 保护；选择固定 ISP 会恢复保护并核对出口。切换会重载规则并短暂中断现有连接。

固定 ISP 连接

连接原理与验证边界

切换时先阻断受保护流量并断开旧连接；只有新路径的出口 IP 精确匹配配置才放行。核对失败保持阻断，不借其他 IP 恢复访问。巡检证据只代表检测时刻，供应商之后更换 IP 仍会触发阻断。

更新与维护

界面更新保持网络服务运行；完整更新先下载并检查差异，涉及核心程序时会弹出独立的停服确认。取消确认不会停止服务。旧版需先完整升级一次才能热更新界面。

更新器会询问是否下载官方 Release，保留用户配置和回滚备份。仅更新界面不会改变核心版本。
