Agent 出口控制器 · 便携版 0.1.0（初版）
==========================================

它做什么
--------
让 AI 用的浏览器（Edge、Chrome）和命令行工具（Claude Code、Codex）走你自己配置的固定出口代理，
同时把系统时区调成和出口一致，并逐项检测是否真的生效。其他软件不受影响：不修改系统代理。

第一次使用
----------
1. 双击 aec-tray.exe。右下角托盘出现一个圆点图标（可能藏在「^」里）。
2. 第一次会自动打开「出口与时区设置」网页：填你自己的出口地址、端口、用户名和密码，选目标时区。
   - 密码存进 Windows 凭据管理器，不写进任何文件。
   - 想让程序自动改系统时区，勾选「进入 Agent 模式时把系统时区改成目标时区」；退出时会改回去。
3. 托盘菜单 →「进入 Agent 模式」。等图标变色：
   - 绿色：所有硬门槛检测通过，可以用了。
   - 黄色：有检测没通过或正在进行，点「查看检测结果」看是哪一项。
   - 红色：上次没有正常恢复，菜单里有「恢复」。
   - 灰色：日常模式，什么都没改。
4. 从托盘菜单打开 Edge / Chrome / Claude Code / Codex。只有从这里打开的才走出口。
   浏览器用的是独立的配置目录，不影响你平时的浏览器数据。
5. 用完点「退出 Agent 模式」：关闭它打开的浏览器、改回时区、停止代理。
   终端窗口不会被强行关闭，请自己关掉。

遇到问题
--------
- 托盘菜单「复制排查提示词」：生成一段已去掉密码的说明，粘贴给任意 AI 助手即可。程序不会自动发送任何东西。
- 「打开数据和日志目录」：data 文件夹里有检测结果、日志和快照。
- 注销或关机时，程序会先自动恢复时区再让系统继续。

注意
----
- 目前只支持 Windows 10/11，需要本机已安装 Edge 或 Chrome（不会自动下载）。
- 程序没有数字签名，第一次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」。
- 如果电脑上还有别的会改时区或系统代理的工具在运行，程序不会去改时区，
  时区检测会显示「未知」，原因写在检测结果和排查提示词里。
- 删除：先在托盘「退出程序」，再删除整个文件夹；凭据管理器里以 AgentEgressController: 开头的条目可以手动删除。
