Agent 出口控制器 · 便携版 0.3.0（预览版，Windows x64）

第一次使用
1. 完整解压 zip，保留 portable.flag 和 bin 目录；不要只复制 aec-tray.exe。
2. 双击 aec-tray.exe，托盘出现圆点，首次打开本机设置页。
3. 填自己的 HTTP/SOCKS5 出口、端口、账号与目标时区，保存。
   直接连不上出口时可开启 IPRoyal 官方公开中转预设或自定义 Shadowsocks 隧道。
   预设只有中转参数，仍需要自己的出口账号；节点可用性取决于网络与供应商。
4. 进入 Agent 模式，从托盘打开 Edge/Chrome，等待本地检查页回报。
   灰：日常；黄：失败/未知或处理中；绿：全部硬门槛通过；红：恢复未完成。
   未打开浏览器时缺少时区与语言证据，保持黄色是正常的。
5. 检查通过后使用 AI 服务或从托盘启动 CLI。退出时恢复已接管设置并关闭本应用浏览器。
   CLI 窗口自己关闭；恢复完成前不要删除程序目录。

分流与系统代理
默认全部走出口；选择分流时目标站走出口，其余默认直连，可选自己的本机日常代理。
开启 Windows 系统代理接管后，遵循系统代理的桌面程序也使用这套路由。
系统代理与时区分别按显式开关、快照和外部写入者检查决定能否真实修改。
发现其他程序改写系统代理时会告警并撤销就绪，不反复抢回；处理冲突后重新进入。
不使用 TUN，不修改防火墙、路由表或全局环境变量，不下载浏览器或其他组件。

导入已有路由（先退出 Agent 模式，在便携目录打开 PowerShell）
  .\aec-dev.exe profile import .\my-routing.yaml --dry-run
  .\aec-dev.exe profile verify .\my-routing.yaml
  .\aec-dev.exe profile import .\my-routing.yaml
  .\aec-dev.exe profile check
导入只替换路由，保留出口与其他设置；凭据迁入本机凭据管理器，原 YAML 不变。
原档案备份在 data\profiles\profiles.json.before-import-*。
设置页默认保留导入表；选“全部走出口”或“分流”会替换整张表。
托盘切换 select 组、保存选择并重新检测；现有连接可能保持原出口。
固定出口模式用看板选择直连/官方隧道/单节点第一跳；先阻断并断开旧连接，精确 IP 核对后放行。
启用保护前先退出并填写精确预期 IP。固定模式无自动直连回退，失败不换出口。
保护域名优先于普通规则；约 30 秒巡检不能保证供应商两次检测间永不换 IP。
看板可新增、移除、排序站点与规则，普通网站仅测可达性，不冒充出口 IP 证据。
未知字段、规则、UDP 或 provider 会拒绝导入；完整格式见 docs\USER-GUIDE.md。

数据、交付与排查
档案是 data\profiles\profiles.json；状态、日志、快照、浏览器数据也在 data\。
私人密码存在当前用户 Windows 凭据管理器，条目前缀 AgentEgressController:。
内核所需密码会短暂出现在生成配置中，退出清理；不要分享使用过的 data、日志或含密码 YAML。
给其他用户只发全新 zip、SHA256SUMS 与无私人凭据示例，每人在本机填自己的账号。
本项目是 Windows 本机出口控制器；远程 AI API 网关需另外部署。
GEOSITE/GEOIP 或“国内直连”需要可信 GeoSite.dat、GeoIP.dat 放在 bin\；包中不附带，不自动下载。
没有这些文件时关闭国内直连；相关规则会在预检明确报缺项。
本机需安装 Edge 或 Chrome；程序未签名，运行前核对 SHA256SUMS.txt。
普通账号的全局写入权限、桌面客户端遵循代理情况仍需实机确认。
托盘“查看检测结果”给证据；“复制排查提示词”不自动发送，分享前可遮盖 IP。
恢复失败先重试；确认保留现状意味着接受未恢复设置，不等于恢复成功。
卸载前退出并完成恢复，再删目录；凭据条目可按前缀手动清理。

打开入口与登录自启
托盘“打开看板”或 aec-tray.exe --dashboard 打开本机页面，已有实例时转交请求。
托盘和看板均可启停登录自启，默认关闭；登录后尝试进入，仍检查恢复状态和接管门。
“创建桌面和开始菜单快捷方式”生成托盘/看板各两个入口，开始菜单搜索 Agent Egress。
命令支持 --enable-autostart、--disable-autostart、--create-shortcuts。
移动、升级、卸载前关闭自启，移除旧桌面和开始菜单入口，再在新目录重新注册。
同名注册/快捷方式属于另一安装时拒绝覆盖；不注册系统服务或文件关联。
