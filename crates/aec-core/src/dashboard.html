Agent 出口看板

连接到固定 ISP

切换先阻断并断开旧连接，核对配置的出口 IP 后放行。失败时保持阻断，不切换到其他出口。检测只代表检测时刻，供应商更换 IP 会在后续巡检时被阻断。

受保护站点

这些域名及其子域名优先走固定 ISP，普通规则不能覆盖。删除站点会取消该站点的保护。

分流规则

按从上到下的顺序匹配。匹配类型和出站从现有选项选择；域名、IP 段等匹配内容自行填写。

匹配类型内容出站不解析 DNS顺序 / 删除

密钥在「出口设置」中填写，保存在 Windows 凭据管理器，看板不回显密钥。

出口与隧道设置

启动入口与登录自启

登录自启会打开本安装的托盘并尝试进入 Agent 模式。上次未恢复、出口检测失败或接管门未打开时，不会显示已就绪。

快捷方式分别打开托盘和看板；开始菜单可搜索 Agent Egress。移动便携目录前先关闭自启，移动后重新创建入口。
